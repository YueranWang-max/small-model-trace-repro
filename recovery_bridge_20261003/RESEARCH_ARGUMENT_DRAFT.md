# 论文主线与当前证据边界

## 一句话说明读者将了解到什么

本研究检验：大模型中有效的推理轨迹复用，能否让本机小模型更准确、更经济地完成图推理，并找出它何时有效、何时失效。

这是研究问题的表述，不是已经证明的结果。最终摘要中的发现句必须等待新对照、独立核验和成本分析完成后写定。

## 组织顺序

1. 原研究提出的轨迹作为状态，以及我们的迁移问题。以 Zou 与 Tang 的 Trace as State 原文为依据，区分理论命题、前沿模型实验与本机有限预算实验。
2. 忠实迁移：保留原文、题目与真实 thinking 轨迹，控制顺序、采样、输出格式、窗口和输出上限。先报告原始轨迹方法的效果与失败，不把后续表示改造混入“复现”。
3. 能力边界：源任务是否足够可靠、失败是否随长度或题型增加、格式与预算失败占多少。这一部分由新 1.7B/8B 独立对照补充，尚在运行。
4. 探索性改进：节点身份无损重编码、完整方向索引、推理模式。每一种都与相应同题对照比较；说明外部程序承担的工作与恢复字典开销。
5. 质量与成本的联合判定：计入所有生产者调用、重复读取、失败与准备开销。模型 token 不等于实际运行时间或货币成本。
6. 局限与可复验材料：小样本、多个探索阶段、有限输出预算、图任务与文档阅读任务的区别，以及中断记录。不能从受限配置失败推论原理论被反驳。

## 当前可写的结果（来自已完成历史阶段；D: 恢复后复查原始材料）

- 五轨迹实验：4 张图。轨迹前置 F1 77.51%，后置 70.64%，无轨迹重读 61.87%；前置与重读的准确匹配率均为 15%。前置全路径 token 约为重读的 8.07 倍。F1 的方向性改善尚未形成稳定的精确答案或成本优势。
- 身份重编码：8 张图。原标识 F1 43.71%，紧凑标识 58.94%；总模型 token 减少 50.46%。仍有一次紧凑条件长度终止，预设可靠性门槛未通过；普通原标识对照差异区间跨零。该信号应进一步验证，不能宣称方法突破或信息论意义的任务无损能力。
- 推理模式：16 张图。启用 thinking F1 37.84%，关闭 16.43%；关闭节省 token，但显著降低本批题目表现。预先规定的题型路由同样未满足质量与成本联合门槛。
- 完整方向索引：96 次计划调用中 94 次已持久化，第 95 次结果和 token 未知，第 96 次未到达。尚未审计，不能填入完整平均分，也不能通过补跑覆盖原始缺失。

## 正在补齐的证据

独立模型对照：16 张新图 × 两次重复 × 两个模型，共 64 次。固定官方数据版本，全部 750 道标签已独立算法核验。1.7B/8B 共享模板、词表 ID 和分词合并规则；每次实际输入数量与驻留配置逐项核验。历史图排除清单由本会话重建，仍待 D: 历史清单交叉核对。

若 8B 达到冻结的源任务能力门槛，再开展新题上的原生五轨迹迁移对照；不根据此次正确答案选择下一批“好题”。若不达标，应优先解释源任务能力与预算边界，不能再用相同题反复调参制造成功。
