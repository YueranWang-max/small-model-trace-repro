# Prospective short native-state study — frozen before first calibration

## Question and scope

Does one early native thinking state, followed by a fresh reader of the complete original source, improve local Qwen3.5-4B graph reasoning under the same maximum logical input-plus-output token allowance as direct answering? This is an extension of Trace as State, not an exact replication or a claim of first proposing partial-state reuse. Source caps and controls are selected without scoring these cases. The earlier interrupted five-trace study and its costs remain separate.

## Budget and arms

Let I be the complete rendered direct request input and freeze B=I+32768 per graph. Direct, question-first [q,x,q], Re2 [x,q,x,q], and a deterministic algorithmic task-cue prefix each receive output cap min(32768,B-own_complete_input). Preserve the full original prompt, including examples and final task. In append, removing the inserted state block must restore it byte for byte; all other arms retain it as a contiguous unchanged block. The task cue is fixed: Track shortest-path distance; keep visited nodes and the requested frontier.

For each graph/repetition, generate one independent native source with the full direct prompt and output cap1024. This fixed cap is an intentional early-stop intervention, not a successful completed solution. Charge all its input/output tokens, including visible output discarded from the state. Retain only raw message.thinking, without selecting favorable tokens, compression, clipping, answer extraction or access to gold. ## Qualification, scoring and failures

Require exact native rendered input count, matching model/digest, response done=true, an assistant message with string thinking/content fields (absent fields mean empty strings), known nonnegative integer input/output usage with output≤requested cap, permitted stop/length reason, and own postresponse resident context≥65536. The calibration must qualify before formal transmission. One attempt per planned request; no retries/resume/overwriting. On HTTP/client error, input/model/residency/usage qualification failure, local execution error, or inability to construct the neutral count match, stop the whole study and preserve saved responses plus all remaining slots as unknown. Do not replay missing calls. Postresponse metadata failure does not erase a saved raw response or its actual usage.

Strict scoring uses only a normally stopped visible response containing exactly one Final Answer: [node,...] line, after trimming outer whitespace. A node token must consist of letters, digits, underscore, period or hyphen; quoted tokens or additional lines are malformed. Length termination or malformed/nonterminal answers score0; do not extract answers from thinking. Unknown nodes count as false positives, with case-sensitive canonical labels. Exact set F1 and EM use independently reconstructed shortest-path depth labels, including visited-node semantics and start exclusion. Each graph/repetition is retained in the denominator. Unknown/unreached results receive [0,1] identification bounds, not fabricated zero; complete-case summaries are explicitly secondary. Abstention/decline is observed zero, distinct from unknown execution.

## Analysis and advance criterion

Primary candidate is prefix. Average two repeats within graph. Show all seven arms, pergraph paired differences and source/reader qualification/normal-stop counts. On complete known qualified execution, report graph-cluster bootstrap percentile95% intervals from20000 resamples, seed202610400; these intervals are descriptive and not simultaneous. For prefix against direct, question-first, Re2, task-cue and neutral-prefix, use exact two-sided paired sign tests on nonzero graph-level F1 differences and Holm correction across five comparisons. This tests direction consistency, not the mean improvement; report it accurately. Prefix versus append is an additional descriptive order contrast. Source early outputs have no majority/oracle decision role.

A promising candidate gate requires complete known qualified study, primary normal valid outputs≥31/32, F1 point improvement≥.05 over all five controls, lower descriptive paired F1 interval>0 and Holm-adjusted sign-test p<.05 for every comparison, and primary EM point no lower than any control. EM point comparison is not a formal noninferiority claim. It also requires mean full model token cost no greater than the cheapest of the four nonstate controls; every observed deployment must respect B. Declines remain in quality and cost. A gate pass is a prespecified new-case finding requiring a further independent confirmation, not by itself a major breakthrough or broad document-QA result. A failure does not show all partial-state methods impossible.

Report actual complete research workflow time, model-call client/API durations, input/output tokens, source-state size, prompt/serialization/tokenization preparation times, and perdeployment sums of measured components. The latter are reconstructed component totals, not observed contiguous single-deployment timings; do not call them cache savings or hardware-exclusive latency. Logical tokens are not money, energy or GPU operations. This stage does not test genuine multiple-query amortization.

The request-protocol timer includes its rendering preparation, model HTTP call, diagnostic metadata requests and earlier record persistence, ending just before the final record write; prompt-construction time before this timer is separate. Source+reader sums include the full source timer for each state deployment. Report the excluded final logging write and one-off research preparation rather than describing these sums as exhaustive contiguous deployment timing. Declines record their measured prompt-construction time and retain source time.

The private service is not reset between calls. Every graph/repetition begins with a source before its randomized readers, so controls may inherit a warmed model or source-prefix cache. Randomized reader order and API timings are recorded, but this stage does not isolate cache effects, measure cold-start deployment, or establish a causal wall-time advantage.
