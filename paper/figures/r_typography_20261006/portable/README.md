# R figure release

Run Rscript render_all.R from this folder. R 4.6.1, svglite 2.2.2, Cairo and Arial required. All plots are rendered in R from the supplied CSV tables. Python is used only for evidence auditing and file metadata. This release covers the seven completed figures; paired-model results will be added only after the complete audit. Outputs: editable SVG, embedded-font vector PDF and 600-dpi PNG. Final manuscript width is 6.5 inches, source-qualification figure uses 92 percent. Fonts are checked at that final width. Data values and prespecified scoring remain unchanged.
