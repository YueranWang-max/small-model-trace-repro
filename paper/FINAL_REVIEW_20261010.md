# Final scientific and editorial review, 2026-10-10

## Recommendation

A defensible, bounded reproduction-and-extension preprint is ready for author review and local source submission preparation. The main value is a confirmed graph-benchmark accuracy improvement on a locally served1.7B model, together with a documented preparation cost and reproduction boundaries. This is not evidence of a broadly superior inference architecture or a production replacement for exact graph algorithms. No acceptance guarantee or claim that a paper can have no possible problems is made.

## Review findings and resolutions

1. **Overbroad old cost conclusion:** the older five-trace results did not support savings, whereas the new single-trace compact-input package has a favorable secondary comparison against original inputs. Rewrote title, abstract, introduction, discussion and conclusion to separate those studies. The primary new finding remains accuracy improvement over compact-direct, with39.8% more complete model tokens.
2. **Discovery mistaken for confirmation:** retain discovery and24 entirely fresh confirmation graph heads separately, with frozen plans and independently audited responses. No pooled significance, sample extension or successful-subset filtering.
3. **Weak direct baseline:** confirmation includes contemporaneous original-long16384 output alongside original8192 and compact8192. Only the primary prefix-minus-compact effect is treated as confirmatory; all other comparisons remain secondary with unadjusted multiplicity.
4. **Placement overclaim:** front-versus-back trace interval includes zero. No placement superiority or equivalence is asserted.
5. **Source failures omitted:** all24 source passes counted explicitly:22 output-truncated,2 normally stopped but incorrect visible answers,0 qualified exact source answers. Their entire unfiltered native thinking is retained; no visible source answers are inserted.
6. **Capacity conflated with success:** discovery8K inputs fit, but the nonempty exact-in-both-repeats criterion fails. Both the manuscript and report retain this negative finding.
7. **Full-cost ambiguity:** complete single-source model tokens charged to each reused answer, never amortized across repeat seeds. Dictionary bytes and CPU preprocessing archived separately; reported wall times cover model requests, not workflow idle or total energy. No monetary saving is claimed.
8. **Protocol tail unspecified:** the original frozen sign-flip rule omitted one-/two-sided choice. The independent auditor uses the conservative two-sided implementation created before complete collection/effect analysis. Methods explicitly disclose this rather than retroactively claiming an originally specified tail.
9. **Reproducibility detail:** added exact mapping seed rule, one-token label vocabulary, inverse restoration, complete-source round trip, all model caps/seeds/context/runtime, exclusion and cooling/reboot records. New0.40.0 results are not pooled with0.35.1 historical runs.
10. **Figure-label visibility:** inspection found the fifth bar label was suppressed by crowded names. R was revised to short unambiguous Original/Orig.16K/Compact/Before/After labels and regenerated. Three successive reviewed content contracts preserve the correction history.
11. **Historical loss and numeric drift:** exact old Results block, nine vector figures and seven table objects remain unchanged. The new manuscript has11 R figures and8 tables, with45 new claim/scope checks plus27 historical numeric/dependency checks;124 exact table tokens and all30 section headings are checked against the PDF.
12. **Compiler failure:** built-in compiler remains unavailable because Windows sandbox setup fails. Installed external Tectonic compiles the exact dependency candidate successfully;28-page PDF1.7 embeds all44 fonts, with no unresolved references or citations. Fontconfig/PDF ingestion notices remain environment notices, not scientific evidence.

## Residual limitations requiring scope, not invented evidence

Restricted public graph benchmark,24 confirmation graph units, repeated seeds rather than48 independent cases, possible pretraining contamination, untested document transfer, wrapper/content confounding, question-specific preparation, uncertain placement effect and secondary multiplicity. Recoding is deterministic structured identifier shortening, not a proven prose compression method. Formal third-party execution attestation and continuous exclusive GPU occupancy are unavailable. Broader production claims would require additional independently designed experiments; none were launched to chase a positive result.

## Reader takeaway

Preserving a structured input with short reversible identifiers can reduce its token burden. On the tested local1.7B configuration, adding one short prior thinking trace improves accuracy over that compact direct baseline, at an additional token cost. Compare the complete package against a sufficiently strong direct baseline and retain both successes and failures.
