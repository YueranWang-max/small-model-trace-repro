Reproducing Trace as State on Local Small Models:
Accuracy and Boundary Conditions
Yueran Wang∗
October 2026
Abstract
Trace as State reuses prior reasoning before the original context to guide a model’s subsequent pass.
We examine its transfer to locally served small models using oﬀicial directed-graph questions. A prospec-
tive twelve-graph replication retained five source traces, five paired reader repeats and the original source,
completing all 240 calls with preserved raw responses. Trace prefix achieved F1 0.7715, versus 0.7351
for trace append and 0.6915 for direct reading. Both descriptive graph-level difference intervals included
zero. Prefix exact match equalled direct reading and was lower than append; its preparation-inclusive
token cost was 8.53 times direct reading. Separate native source trials achieved high accuracy, but five-
trace reuse exceeded a configured 131,072-token context on the first follow-up graph. A shorter-state
trial remained incomplete and sensitive to visible-answer parsing. These findings distinguish source com-
petence, reader feasibility and uncertain placement benefits. They delimit the tested local configurations
without establishing a general small-model advantage.

Introduction
Reasoning discovered during one pass over a document may help a model interpret that document on a
subsequent pass. Zou and Tang’s Trace as State method makes this reasoning available before the original
context [1]. Its matched placement control puts the same reasoning after the context, while retaining the
question at the end. Their frontier-model experiments support a placement advantage across the evaluated
long-context tasks.
Whether this advantage transfers to locally served small models remains an empirical question. A smaller
model may generate a useful trace yet fail to use it reliably. The added traces must also fit its usable context
window. These constraints matter for reproducing the intervention, even when reducing inference cost is not
the objective.
We examine this transfer using oﬀicial GraphWalks questions, local Qwen models and archived request–
response records. We preserve the original graph and compare reasoning placed before and after it. The
reproduction adapts model size, input length, runtime and generation limits to local resources. It there-
fore tests the method under these specified conditions, rather than reproducing the original frontier-scale
benchmark scores.
Our contribution is a reproduction and boundary study.
We document the adaptations needed for
local execution, distinguish source competence from second-pass benefit, and identify context and scoring
constraints. Preparation costs provide an additional deployment analysis, not a requirement for reproducing
an accuracy effect. The study asks when prior reasoning can be reused reliably by a small model, and which
constraints limit that reuse.

Methods
2.1
Reproduction scope and experimental conditions
Let x denote the graph context, q its operation, and T a serialized block of prior reasoning. Trace prefix
and trace append use [T, x, q] and [x, T, q], respectively. Both receive the same realized T and retain the
complete original graph. Direct reading uses [x, q]; question-first reading uses [q, x, q]; Re2 uses [x, q, x, q]
within one request. A separate fresh request containing [x, q] is not Re2.
The original study used five source traces and five reader repeats, with each reused trace capped at
its first 50,000 characters. Both completed short-graph studies retained this trace count, repeat count and
placement comparison. Its source and reader output limits were 4,096 and 8,192 tokens, respectively. These
limits differ from the original provider settings and constrain the reproduction claim. Appendix B lists the
retained and adapted components.
Tasks and selection.
The oﬀicial-data archive contains 750 released graph questions. We used directed
breadth-first search (BFS) and parent-retrieval tasks. Gold answers were recomputed from graph edges before
scoring. Study-specific selection used catalogue length, task type and exclusion of previously selected graph
identities. Earlier selection was deterministic. A separate prospective replication randomly selected six new
graphs per task from a restricted short-input population; it was not a random sample of all graph questions.
Seeds supplied repeated measurements within graphs and did not increase the number of independent graph
units.
Models and interfaces.
We used the nominal Qwen3-1.7B, Qwen3-8B and Qwen3.5-4B variants with
native thinking exposed separately from visible answers.
The main configurations are listed in Table 1.
Model digests, runtime versions, sampling settings and complete prompts are preserved in the frozen archives.
Native Qwen3.5 studies used Ollama 0.35.1 and a fixed general-thinking profile. Its temperature was 1.0,
top-p 0.95, top-k 20 and presence penalty 1.5. The earlier Qwen3 short-trace study used temperature 0.6,
top-p 0.95 and top-k 20. These settings were not pooled as a model-size experiment.

Prospective short-graph replication.
Before collecting new responses, we froze a twelve-graph protocol
and its complete allocation schedule. All graph heads selected in existing oﬀicial-study freezes were excluded.
Within the catalogue interval [2000, 3500) characters, the resulting pools contained 34 parent questions and
nine BFS questions with distinct graph heads. Six were sampled without replacement per task, using seed
202610060. Graph order and reader-arm order within each repetition were randomized using the same seeded
generator. Five source seeds (202610061–202610065) and five matched reader seeds (202610071–202610075)
supplied 240 planned calls. Model digest, original serializer, context and source/reader caps matched the
initial short study. Decoding used temperature 0.6, top-p 0.95, top-k 20, minimum-p 0 and repeat penalty 1.
The native server version was 0.35.1. Complete requests were saved before transmission and exact response
bytes before parsing. No call was retried. Sequential calls were separated by five seconds, and graph blocks
by sixty seconds. This was a locally frozen prospective protocol, not an external preregistration.
Trace construction and controls.
Source reasoning was read from the native thinking field; the separate
visible answer was excluded. Incorrect and length-terminated source traces were retained according to each

Set semantics remove duplicate predictions but retain incorrect nodes. Scoring used visible answers only
and never extracted an answer from thinking. Known malformed or length-terminated outputs received zero
under their respective protocols. Valid empty answers were scored normally, with an always-empty baseline
reported where relevant.
Answer interfaces.
The earlier native studies accepted a valid terminal visible Final Answer: [...]
line after a normal stop. The early-state study required that line to constitute the entire visible response.
Its later relaxed parser was explicitly post hoc and did not replace the primary scores. Recoding protocols
also differed in their treatment of unmapped nodes. Identity recoding invalidated such predictions, whereas
indexed-source scoring counted them as false positives. Scores were not pooled across these rules.
Call qualification.
Input counts, response metadata and resident model digest/context were checked
against the recorded request. Qualification established compliance with the study’s interface, not answer
correctness. A qualified response could still be malformed or reach its output limit. A returned response
that failed interface qualification remained undetermined under the applicable primary protocol.
Interrupted execution.
Unknown responses were bounded over the original planned denominator, rather
than scored as zero or replayed. For N planned outcomes with m unknown values, the F1 bounds were
[∑F1/N, (∑F1 + m)/N].
Known unsent budget declines were deployment failures, not model answers.
Client errors retained their protocol-defined failure scores and unknown usage. Unknown token usage made
the reported cost a lower bound.
2.3
Statistical analysis and resource accounting
Reader repetitions were averaged within graphs before comparisons across graphs. The short-trace study
used 20,000 graph bootstrap resamples, seed 202610040, for descriptive 95% percentile intervals. Its four
graphs did not support a broad population claim. The twelve-graph replication specified prefix-minus-append
F1 as its primary contrast and prefix-minus-direct as secondary. Each task stratum contributed equally. Its
descriptive percentile intervals used 20,000 bootstrap draws of six graph units within each task stratum, seed
202610066. All twelve selected graphs and all repeated outcomes were included, without score-dependent
stopping. Subsequent studies retained their own frozen analysis families and screening criteria (Appendix A).
These criteria governed advancement to further research; they were not universal definitions of successful
replication or formal noninferiority tests.
Deployment-token accounting included the complete source inputs and outputs plus one reader’s input
and output.
Repeated reader calls estimated that reader cost; they did not divide the preparation bill.
Research-run totals were reported separately and included calibration where performed. Token accounting
did not establish latency, energy or cache-related computation savings. The prospective replication sepa-
rately recorded observed request wall times, without an exclusive-hardware or comparative-latency claim.
A dedicated API endpoint also did not establish exclusive hardware use. No existing protocol, response or
primary score was changed during the manuscript revision.

Results
3.1
Initial short-graph reproduction showed an uncertain placement benefit
The completed Qwen3-1.7B reproduction comprised four new oﬀicial graphs and eighty calls. Each graph
supplied five source traces and five paired repeats of each reader condition.
All requests met interface
qualification, although five sources and one direct reader reached their output limits.
Trace prefix achieved mean F1 0.7751, compared with 0.7064 for trace append and 0.6187 for direct
reading.
The prefix-minus-append difference was 6.87 percentage points, with a descriptive interval of
[−1.92, 14.33] points. The prefix-minus-direct difference was 15.64 points, with an interval of [−0.39, 31.67]
points.
Both intervals included zero.
Exact match was 0.15 for prefix and direct reading, and 0.05 for
append. Thus the F1 point estimates favored prefix placement, but this small study did not establish a
reliable placement advantage.
Charging all five source calls gave prefix approximately 8.07 times the tokens of direct reading. These
costs quantified resource requirements separately from the placement comparison. The unequal source and
reader caps also prevented a same-budget first-pass versus second-pass interpretation.
3.2
Prospective replication retained uncertainty and task dependence
The twelve-graph follow-up completed all 240 planned calls: sixty sources and sixty reader responses per
condition. Every call passed the recorded interface checks; none was declined for context or had unknown
usage. Twelve sources reached their 4,096-token limit. Prefix and append each produced sixty normal-valid
visible answers, compared with 59 for direct reading; the remaining direct response reached its output limit.
Incorrect and truncated source reasoning remained in the shared trace block.
Mean F1 was 0.7715 for prefix, 0.7351 for append and 0.6915 for direct reading (Figure 1). The primary
prefix-minus-append difference was 3.64 percentage points, with a descriptive interval of [−0.65, 8.33] points.
The secondary prefix-minus-direct difference was 8.00 points, interval [−3.00, 17.98] points. Both intervals
included zero. EM was 0.3333, 0.3833 and 0.3333 respectively: the higher prefix F1 did not extend to exact
match. Two graphs had empty gold answers; an always-empty response therefore scored 0.1667 in both
metrics over this sample.
The prefix-minus-direct F1 point difference was +20.79 points for parents but −4.80 points for BFS.
These six-graph strata did not establish a task-specific causal mechanism. They showed why an aggregate
positive point estimate should not be described as a uniform improvement. The follow-up remained separate
from the initial four graphs; their scores and intervals were not pooled.
Charging all five source calls plus one seed-averaged reading gave mean deployment costs of 34,901.15
tokens for prefix, 34,622.07 for append and 4,093.48 for direct reading. Prefix cost 8.53 times direct reading
under this single-question contract. The complete research run consumed 2,308,239 model tokens. Observed
request wall times summed to 4,115.32 seconds, excluding the planned idle gaps; this was neither total
elapsed deployment time nor a hardware-exclusive latency comparison.

3.4
Five native traces exceeded the configured reader context
The next trial planned sixteen long-BFS graphs, five sources per graph and five repeats of five reader
conditions. On the first graph, prefix and append each required 144,677 input tokens. This exceeded the
configured 131,072-token context before any reader output was generated (Figure 3). Both trace conditions
were declined under the frozen resource rule, without shortening their trace block.
The trial subsequently stopped after a returned response failed its resident-model check. Of 480 planned
formal slots, fourteen returned qualified responses, eight were budget declines, one returned response was
unqualified, and 457 were unreached. These categories preserved 22 determined deployment outcomes and
458 unknown outcomes. The archive established first-graph infeasibility under the specified configuration,
but not a sixteen-graph quality effect.
The frozen inputs also permitted a conditional cost calculation. Let I be one complete source input and
C the direct output allowance. Five source inputs alone cost 5I, whereas one direct prediction costs at most
I + C. Hence
I > C/4
=⇒
5I > I + C.
All sixteen planned inputs satisfied I > 8192 with C = 32768. Under this single-prediction accounting
contract, five complete sources could not be cheaper than direct reading.
This bound did not apply to
latency, caching, different output caps or preparation reused across different questions.

Early-state adaptation remained incomplete and format-sensitive
A separate adaptation shortened preparation to a 1,024-token source cap. Seven reader arms retained the
complete graph and shared the same total-token allowance. The comparison included direct, question-first,
Re2, task cue, prefix, append and a paid neutral prefix.
The runner ended without a terminal completion record. Later inspection confirmed its absence, but not
the cause or exact termination time. The archive contained 149 qualified responses, including calibration
and source calls, and one request-only record. Of 224 planned reader outputs, 129 were known. Known
research usage was at least 3,621,241 tokens.

3.6
Additional controls identified separate sources of variation
Representation and decoding studies tested interventions distinct from trace placement. Reversible compact
node names improved the F1 point estimate by 15.23 points and reduced tokens by 50.46%. Its eight-graph
interval against original names was [−21.15, 40.98] points, leaving the quality effect uncertain. Thinking-off
and a fixed task route reduced tokens while lowering quality (Appendix G).
The indexed-source study saved 94 of 96 planned responses. Its primary indexed-off candidate failed
the frozen criterion. A secondary compact-on comparison remained positive under worst-case missing-score
bounds, but unknown usage prevented a complete cost comparison (Appendix F). Small longer-input and
sampling studies also showed sensitivity to decoding and empty-answer baselines. They did not identify a
single causal sampling parameter or a universal long-input failure.
4
Discussion
The local experiments provided limited accuracy evidence alongside concrete execution and evaluation bound-
aries. Both completed short-graph studies favored trace prefix in mean F1, but the initial four-graph and
prospective twelve-graph intervals included zero. The latter also showed lower prefix EM than append and
opposing prefix-versus-direct point differences across tasks. The native source study showed that selected
graph questions could be answered reliably under a different configuration. It did not establish that a reader
would benefit from those traces.
Relation to Trace as State.
The original method supplies prior reasoning before an unchanged source,
allowing it to guide rereading [1]. Our placement comparison retained that intervention. Differences in
models, task lengths, output limits and interfaces prevented a direct comparison with the original benchmark
scores. The local uncertainty therefore did not contradict the reported frontier-model result. The original
paper also acknowledged additional latency and token costs; our accounting quantified a particular local
configuration rather than identifying a flaw overlooked by its authors.
Separating the constraints.
Source competence, reader feasibility and placement benefit are distinct
questions. A successful source pass answers only the first. Context overflow prevents the second pass from
testing placement at all.
Output-format sensitivity limits interpretation of a measured score difference.
Treating these conditions separately prevents an execution failure or parsing difference from being mistaken
for a failure of the underlying reasoning principle.
Implications for further reproduction.
Further long-input reproduction should first ensure that the
intended trace block and output reserve fit every selected input. It should then compare identical trace
content before and after the source with paired graph measurements. Semantic correctness, strict output
compliance and truncation should be specified separately before collection. Fewer traces or compressed traces
change the intervention and require their own matched controls. These are prospective requirements, not
additional findings of this study.
Contribution of the boundary study.
The primary contribution is a specification of local reproduction
conditions. The evidence identifies qualified source configurations, cases where the intended second pass
cannot run, and a scoring confound requiring explicit control. It narrows the conditions for a meaning-
ful small-model test. Representation changes and source-free experiments remain exploratory extensions,
separate from the placement evidence.
5
Limitations
The initial placement study used four graphs with deterministic selection. The prospective follow-up used
twelve randomized graph units from restricted, previously unselected short-input pools, including only nine
eligible BFS graph heads before sampling. Five readings of each graph did not create additional independent
graph units.
Most other study selections remained deterministic.
The results cannot estimate general
8

performance across tasks, models or domains. Native long-trace and early-state trials were interrupted, so
their full-sample quality effects remained unknown. Model families, input complexity and decoding settings
changed between studies, preventing architecture-only or scale-only attribution.
Graph questions admit exact conventional algorithms. They served as controlled probes of model behav-
ior, not evidence that language models outperform graph parsers. Legacy synthetic and document exper-
iments had different protocols and incomplete response provenance; they were excluded from the primary
evidence. Local hashes and recorded runtime snapshots support consistency checks but do not prove con-
tinuous exclusive hardware use or third-party execution authenticity. Token counts alone do not establish
energy, monetary or latency savings.
6
Conclusion
We reproduced the Trace as State placement intervention under specified local small-model conditions and
examined its limits. The initial and prospective short-graph comparisons showed uncertain F1 gains, while
other trials exposed context overflow and answer-format sensitivity. These findings specify constraints that
future local replications must control. Conclusions remain restricted to the tested models, graph questions
and budgets.

Study-Specific Advance Gates
These gates were written in the respective protocols before their calls. They are screening rules for further
research, not interchangeable definitions of successful replication or statistical confirmation. The descriptions
below locate the original criteria; the frozen protocol and executable analysis govern each result. Failure
does not establish impossibility for other models, budgets or tasks.
Short five-trace pilot.
Under protocol_official_graph_five_trace_20261003.md, inputs must qual-
ify and all readers must normally terminate. Prefix F1 must exceed both append and fresh reading by at
least five percentage points, with EM no lower and at least two of four graph differences positive against
each control. This gate does not require economical deployment; all five source calls are nevertheless charged
in reported cost. One length-terminated fresh reader prevents a pass.
Identity recoding.
Under protocol_official_graph_identity_recode_20261003.md, inputs must
qualify and every compact response must be valid. Compact F1 must exceed original and long-alias F1
by at least ten percentage points, with EM no lower and at least four of eight positive graph differences
9

for each comparison. Compact model-token cost must not exceed original cost. The compact arm has one
length termination, so a favorable aggregate point estimate does not pass the gate.
Thinking mode.
Under protocol_official_graph_reasoning_mode_20261003.md, qualified inputs
and at least 31 of 32 normal outputs are required for the off or fixed-route candidate. Relative to always-on,
F1 may decrease by at most five percentage points, EM must not decrease, and complete token cost must
fall by at least 30%. A route dominated by always-off is not advanced. These are point-estimate screening
tolerances, not formal noninferiority evidence. Both observed candidates fail.
Indexed source.
Under protocol_official_graph_indexed_source_20261003.md, inputs must qualify
and indexed-off must produce at least 15 of 16 normal outputs. Its F1 must exceed both original-on and
original-off by ten points, with EM no lower; it must exceed compact-off by five points with at least four
of eight positive graph differences. Total model tokens must not exceed original-off. The observed indexed-
off comparison against original-on cannot satisfy the F1 condition, irrespective of the other missing arms.
Compact-on was not this primary candidate.
Model bridge and native source qualification.
The bridge’s protocol_official_graph_model_
bridge_20261003.md requires qualified inputs, at least 31 of 32 normal parseable 8B outputs, F1 at
least 0.70 and EM at least 0.50.
Even favorable missing-outcome bounds fail that gate.
The separate
native-source qualification protocol requires all sixteen outcomes and usage counts known and qualified, at
least fifteen normal parseable outputs, and the same F1/EM thresholds. That study passes. These are
source-competence gates, not evidence that a second-pass reader benefits from traces.
Native long five-trace intervention.
Its frozen protocol specifies six primary prefix comparisons: ap-
pend, fresh, question-first, Re2, set mode and node majority. A practical signal needs mean F1 improvement
of at least 0.05, a positive lower descriptive paired interval and Holm-adjusted two-sided sign-test p < 0.05.
Ordering evidence concerns append; an accuracy candidate must satisfy the signal criteria against all five
non-trace controls, have EM point values no lower, at least 95% normally parsed outputs, known planned
outcomes and qualified returned responses. A cost candidate additionally cannot exceed the cheapest quali-
fied non-trace control’s full logical-token cost. The interrupted archive cannot pass these gates. The all-six
sign-test family must not be confused with the short-state study’s five-control family.
Short native state.
Its prospective criteria are given in the main text. The frozen protocol is partial_
state_protocol_20261004.md in recovery_bridge_20261003. This study ended incomplete and did not
pass. Seven of eighteen known prefix outputs were not normal-valid, making its threshold of 31/32 unattain-
able even if all fourteen missing outputs were valid. The prospective gate also required complete qualified
execution, F1 gains of at least 0.05 over five controls with positive descriptive paired intervals and Holm-
adjusted sign-test significance, EM point estimates no lower, and complete deployment-token cost no greater
than the cheapest nonstate control. The post hoc visible-answer sensitivity does not alter these original
criteria.

included calibration, budget declines and request-only records, not 590 valid answers. Returned visible an-
swers were rescored according to their study-specific frozen rules. Request hashes, frozen dependencies, model
snapshots, graph identities, recorded usage and selected graph bootstrap intervals were checked against the
archives.

Scope of this addition.
This separately audited stage asks whether a local small model can solve the full-
source graph tasks under a qualified native-thinking interface. It does not test a trace-feedback intervention.
The manuscript’s broader migration reorganization remains in progress; the independently frozen five-trace
follow-up subsequently terminated early, as reported in Section E. This appendix must not be interpreted
as a completed positive replication of Trace as State.
Prospective protocol and verification.
We used the fixed local qwen3.5:4b model digest, Ollama 0.35.1,
the archived oﬀicial general-thinking sampling profile, a 65,536-token context allocation and a 32,768-token
output allowance. The original graph, system instruction and terminal-answer format were retained. Eight
distinct oﬀicial GraphWalks graphs were selected in dataset order after excluding 58 earlier oﬀicial-study
graphs and 16 model-bridge graphs, including interrupted or unreached cases. Two fixed source seeds were

independent auditor reconstructed selection from historical frozen manifests, recomputed BFS labels using
queue distances, rendered the oﬀicial Jinja template independently of the runner’s renderer translation, and
verified intended payloads, native input counts, model identity, resident context and usage. All 17 returned
records qualified; the calibration was excluded from primary task scores and retained in costs.

Interpretive limits and next test.
Model family, training, tokenizer, sampling profile, output allowance
and fresh graph identities differ from earlier bridges, so cross-stage differences do not identify a parameter-size,
architecture-only or budget-only causal effect. “Fresh” means unused in this research workflow; pretraining
non-overlap with these public graphs has not been established. Longer cases also contain larger graphs. The
result qualifies a local source configuration for further study, but establishes neither trace-reuse gains nor
source-free suﬀiciency. A source-performance gate is not a necessary condition for studying trace rescue:
the original paper also reported trace benefits from much weaker first-pass scores. The gate’s own verdict
remains unchanged.
The former unfrozen four-stratum follow-up draft failed offline feasibility because only three unused short
BFS graphs remained where four were required. Its implementations and failure identity were preserved.
Together with the pilot’s short-task and long-parents ceiling, this motivated a separately frozen study of
16 fresh long-BFS graphs, selected in dataset order with no future case-score filtering. This task focus is
pilot-informed; it is not an outcome-independent task-family choice. The follow-up retains five native source
traces, five repeats per reader, identical bundles in prefix and append, full-source sampling, Question First
and full-prompt Re2 controls, and distinct node-wise majority and whole-set-mode source-answer controls.
Its 131,072-token context requires a separate logged calibration. A single trace prediction pays for all five
sources and one expected reader. A positive pilot would still require independent fresh-case confirmation.
A structural single-prediction token-cost boundary.
A separate analytic check of the frozen follow-
up inputs establishes a resource boundary without inspecting its solver outcomes. Let I denote the qualified
full-source input-token count and C the common output allowance. A fresh full-source call costs at most
I + C logical API tokens, whereas a prediction paying for five sources incurs at least 5I source-input tokens
before any source outputs or feedback reader. Hence I > C/4 rules out lower one-prediction total-token cost
for this five-source design. All 16 follow-up cases satisfy this inequality at C = 32,768. Their mean five-
source input-only lower bound is 56,303.4375 tokens, exceeding the fresh-call input-plus-maximum-output
upper bound of 44,028.6875. These are conditional planned-request bounds, not measured interim perfor-
mance means. Actual qualified inputs must match the independently rendered counts and returned outputs
must obey the frozen allowance. The cost criterion remains unchanged, and the accuracy and same-state
placement questions remain open. The bound concerns logical token accounting, not cache-adjusted compu-
tation, latency, monetary cost or all possible trace methods. Fewer source passes, cheaper evidence readout
or preparation reused across genuinely different deployed questions require separate new-case experiments;
repeated samples of one question do not justify dividing the source bill by five.

The prospective follow-up fixed 16 fresh long-BFS graphs,

The process terminated after ordinal 24 because the post-response residency check failed.
Independent
reconstruction of dataset selection, queue-based gold labels, request rendering, seed order, native trace
serialization, joint input feasibility, usage and the consecutive execution prefix passed. The frozen analysis
was then executed unchanged.
Only the first graph’s source bundle was generated.
Of the 480 scored
slots, 14 returned qualified responses, eight were recorded as untransmitted budget declines, one returned
response was unqualified, and 457 were not reached.
Thus 22 scored outcomes are determined and 458
remain undetermined under the frozen primary rules. Neither a successful audit nor a normal process exit
establishes completion of the planned experiment.
Qualification failure is not a reasoning failure.
Ordinal 24 returned a normal stop, the expected
model name, 11,246 input tokens matching the independently rendered count, and 19,563 output tokens.
Its subsequently archived /api/ps response contained an empty model list, so the frozen digest-and-context

termined. Later read-only metadata showed a different resident model, qwen3:8b, at a 32,768-token context.
The surrounding server log also recorded other /v1/chat/completions requests, that model’s loading, and
GPU-discovery warnings. This temporal evidence is consistent with shared-runtime switching but does not
identify a unique cause or caller. Earlier qualification snapshots do not prove continuous resource exclusiv-
ity. A later model load cannot retrospectively qualify the failed record, and no stopped primary request was
replayed.
Observed context boundary.

declined prefix and append symmetrically. Eight decline records were actually reached; later planned slots
retain the frozen missing-outcome treatment. This is a deployment-feasibility observation on one graph and
configuration, not proof that every remaining graph would fail or that a fitting trace would be ineffective. A
character cap is not a portable token-budget guarantee.
