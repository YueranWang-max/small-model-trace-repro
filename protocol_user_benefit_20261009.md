# New-question user-benefit study, frozen before model responses

Purpose: test a deployable, bounded benefit on the existing local 1.7B model. A positive result is not required by the stopping rule. All negative results and missing outcomes remain reportable. This extends the local reproduction rather than claiming to repeat the original five-trace intervention unchanged.

Two independently selected strata are collected in one frozen schedule:

1. Capacity: twelve previously unused graph heads (six parents, six BFS), randomly chosen from source-only eligible official questions. Original prompt input exceeds 8,192 tokens; reversible compact prompt input is <=3,500 tokens. Compact source + maximum output +64 must fit the full 8,192-token window. No nodes, edges, operation or examples are dropped. This asks whether a 1.7B model can correctly answer at least some complete-source questions that are inadmissible under the original encoding and the same 8K serving contract.
2. Short: twelve unused heads (six/type), randomly selected from 3,500 <= source characters <6,500. Compare original direct, compact direct, and a compact single-trace prefix. All use 32,768 context. Direct caps are 8,192; one compact source cap is 1,024 and prefix reader cap 7,168. Equal maximum generated allowances do not equalize total input tokens or compute. A one-trace adaptation is not the original five-trace placement intervention; no placement-specific mechanism will be inferred without an append control.

Capacity arms: original direct at 32,768 context with 8,192 output allowance (stronger-context reference); compact direct at 8,192 context with 4,096 output allowance; compact single-trace source 1,024 then prefix reader 3,072 at 8,192 context. Original at 8K is a source-only budget-declined feasibility reference, not an executed model error scored zero. The compact-vs-original larger-context comparison changes representation, context and output budget and estimates deployment packages, not an isolated causal recoding effect.
